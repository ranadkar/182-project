# Locked Qwen protocol

Written before model scoring. The primary contrast is continuation minus explicit training in the proportion of **external discrepancy notifications producing a net state change to the typed target** on the 60 existing public test scenarios. Eligibility does not depend on a model's explicit-task performance. Each trained condition uses two paired independent seeds. The frozen base receives one evaluation. All models use greedy first-turn decoding with a 96-token cap. A turn that offers only advice contributes zero to the primary outcome.

Every training branch has an active user goal, an assistant lookup and a tool result. The result gives the reference setting. On a write branch it also gives the verified current setting. On a read branch the current setting remains unknown. The policy can end through either an ordinary closing message or the no_action tool. Each authorization manipulation applies only to the write/read branches. A single JSON record stores the common actions, schemas and state plus the three possible intervening user messages. Splits use disjoint workflows, field schemas and objects. The native system preamble, generic get/set convention, scalar types and no_action deliberately transfer across splits.

The fitting budget is 256 examples, one epoch, 32 updates per adapter. The 32-example engineering pilots use a separate seed, a subset of the training data, four updates and separate output directories. Each substantive run starts fresh. Fixed final-step adapters go to evaluation. Identical initialization and case order within seed isolate the intervention; different seeds capture initialization, shuffling and dropout variability. The acknowledgment arm adds an unrequested factual restatement of information already available to the model. The explicit arm repeats the target in the same slot. The primary comparison includes the additional user turn. Explicit versus acknowledgment compares content with that turn present. Acknowledgment versus continuation tests adding a factual turn and its content together.

Model selection uses no factual evaluation labels or responses. Three disjoint settings per calibration operation check native typed reads, writes, and no_action. At least two of three in each operation are required for engineering calibration. If an adapter fails, keep the failure visible and examine interface or model competence before drawing conclusions. Validate the two pilot arms on earlier-goal decisions in separate development workflows. Do not alter budgets after inspecting final test behavior. Run the 12 reserved cases only after all substantive adapters and scoring rules are frozen. Report them separately as two-domain transfer evidence.

Secondary measures include first-turn executable calls, valid writes, recognizable attempts naming the setter, read-only turns, any read, idempotent writes, changed state, off-target change, changes on ordinary facts, explicit no_action, ordinary text, empty and invalid responses. A write to the (counterfactual) discrepancy target on an ordinary control remains unnecessary. Report paired user versus external and discrepancy versus ordinary contrasts. Report requested-write correctness, authorized decisions by type and ordinary-close form separately. Inspect the meaning of natural-language closure manually.

Estimate 95% percentile intervals by resampling entire scenario families, retaining every model and cell within each cluster and crossing that bootstrap with resampling paired training-seed indices. For the 60 scenarios use the ten source domains as conservative families (six scenarios per domain). Report individual seeds, discordance counts, and an individual-scenario sensitivity interval. Do not count role pairs, checkpoints, or deterministic repeats as additional independent cases. The reserve has only two domain clusters, so emphasize raw paired counts there. Source of variation includes only these synthetic domains and seeds. Zero observed discordances yield a degenerate empirical bootstrap, with limited power to generalize.
