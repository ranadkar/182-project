# Development protocol and final evaluation choices

The intervention is the number of unique negative targets replacing positive targets per 1,000 assistant turns. All conditions begin at the same pinned base weights at NF4 inference precision. Each adapter sees one shuffle of its condition, in 125 eight-example updates. Seeds vary the LoRA initialization and shuffle, with identical material at a given proportion. Final checkpoints are selected by step. A development-only check in original bf16 precision measures the effect of baseline quantization. It is excluded from the training-composition estimand. An adapter is the unit for training variability. A source-question cluster is the unit for evaluation uncertainty.

Use the two endpoint conditions at seed 182 first. Check finite gradients, response-only validation loss, VRAM, generated output syntax, false calls, and valid required calls on held-out preference prompts. If free generations show little change, report uncertainty and inspect whether the positives and negatives have adequate support. A positive direction of effect is never a pass criterion. If there is no valid required call from an endpoint model, or the optimization or serialization is broken, keep official scores sealed and diagnose on development prompts. Run remaining conditions after pilot review, using the same evaluation examples.

Primary behavioral outcomes are false-call rate and required-call decision recall in greedy free generation. Malformed attempts count as decisions to call. Strict correct-call recall additionally requires the reference function and argument values. Four-way free-text classification uses a local rule and is a secondary proxy. Audit outputs for judge errors. No endpoint is contacted or invoked. Keep free generation and MCQ results separate.

The official-data comparison uses deterministic source-cluster samples for laptop feasibility. With the seed in experiment.json, permute BFCL source-question clusters and retain the first 128 for MCQ. Keep all distinct prompts within those clusters, preserving edited questions or tool menus. Collapse identical prompts by stable UUID and exclude conflicting gold decisions for the same prompt. Record these counts alongside the basic schema check of reference calls. For generation, sample 24 distinct prompts per gold class from the official 300-row judge split, ordered by UUID and drawn with the same fixed seed. Cluster related examples for uncertainty in each protocol. The two protocol samples have different inclusion rules. Score each of the four native-format candidate continuations independently. Store summed conditional log probability and log probability per UTF-8 byte, excluding EOS in both. Use the byte-normalized decision for the main MCQ table and report the raw alternative. Rank ties follow released candidate order. No presented option letters. Free generation uses the same no-thinking Qwen prompt (including when tools are absent), greedy decoding and 160 new tokens. Development data lacks four alternatives, so use free generation there. No external judge or BFCL execution score.

Accuracy uses four possible decisions. Fixed-four macro F1 assigns zero F1 to a class with no true or predicted positives. Also report macro F1 over gold-supported classes. The direct class has zero official support and undefined recall. Show precision, confusion counts, invalidity among attempted calls and hallucinated names separately. The paper's narrower hallucination rate is conditional on cannot-answer cases with zero available tools. False-call rate includes every gold non-tool example.

Use 2,000 paired nonparametric source-cluster bootstrap draws, seed 1822026. Reuse each draw for all models and all conditions. Report marginal percentile intervals and paired contrasts to the tool-heavy condition. For means across fitted seeds, resample held-out groups once per draw and apply the same weights to all seeds. Report the empirical seed standard deviation separately. Boundary percentile intervals can collapse on small samples. These intervals condition on the trained models and sampled task distribution. No equivalence or noninferiority claim will follow from a nonsignificant recall contrast.
